# prompts · 分节点备份

[DESIGN](../DESIGN.md) §2.3 的**完整 prompt 全文**在此按宏观节点备份；DESIGN 正文只留 prompt **契约**（注入项 / 输出 schema / 规则要点 / 后置校验）并回链到这里。

## 约定

1. **prompt 属系统层**（行为），**不含任何业务词汇**——业务词汇一律运行时**注入**（`{{...}}`）。这是「系统零内置词表」（DESIGN §1.6）可扫验的前提。
2. **每个 LLM 步必配确定性后置校验**——prompt 负责"生成得像"，校验负责"生成得对"（DESIGN §2.3.0 ②）。
3. 角色标注沿用 DESIGN §3.2：**L0** 无 LLM ／ **L1** 增强 ／ **L2** 主导。
4. prompt 与判据一样**带版本**（DESIGN §5.1 的可迭代纪律）。

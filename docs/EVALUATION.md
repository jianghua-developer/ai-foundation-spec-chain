# 评估结论：本项目已停止

- 日期：**2026-09-15**
- 状态：**已停止**（不再推进，见 [DESIGN](DESIGN.md) 开头的停止声明）
- 本文记录**为什么停**、**沿途实测到了什么**、以及**这次真正留下的东西**。

---

## 一、结论（一句话）

> **本项目反复尝试的每一种形态，都在抢同一个生态位——「独立于对话与代码的中间产物」。
> 而这个生态位是空的：它比记忆重，比代码旧。**

不是"链做得不好"，是**这一类东西不该存在**。

---

## 二、八次否决

全部沿同一条判据链推出，且每一次都有实测或论证支撑。

| # | 尝试的形态 | 否决理由 | 判据 |
|---|---|---|---|
| 1 | **全链**：一句话 → spec 文档族 | 需求/设计**不是一次性能补齐的**；批处理形态会在开发期过期，过期的规格**比没有更糟**（它在撒谎，而下游会信） | 收敛判据 |
| 2 | **页面设计 / 真设计图** | spec → 具体页面**不收敛**：实测 14 个问题，其中 **7 条是"每加一类页面就再来一次"的永久税** | 收敛判据 |
| 3 | **结构骨架图** | 作为 AI 消费品**没有优势**（追问 15 条 > JSON 的 12 条，还引入了"设计注释 vs 界面内容"的歧义）；对人也未必值——让实现方直接做出来更快 | 判断成本 |
| 4 | **接口设计** | 剥掉实现面后只剩"有哪些能力"，**薄到可并入** `resolution.md` | 跨界节点 |
| 5 | **架构设计**（形态与架构初判） | **业务不变量**（不能超卖）该前置；**实现机制**（Redis 预扣）不该——它取决于实现语境、随实现收敛、前置会锁死 | 收敛判据 |
| 6 | **审查器 / 保证类工具** | 给的是**意见**不是**证明**。而错误代价高的地方人只要证明（编译器/测试/类型），自己重推；代价低的地方不值得 | 武器 × 可验证 |
| 7 | **需求收集助手** | 判断成本**结构性过高**——**你无法判断自己没被问到的东西** | 判断成本 |
| 8 | **风险清单访谈小工具** | 形态对了（把不可判的完备性换成可判的清单覆盖率），但：护城河是**行业知识**不是 AI；**单人不需要**（要的是记忆不是文档）；**团队已被流程替代**（issue/PR/评审） | 中间产物生态位 |

---

## 三、同一根因

八次否决全部收敛到同一句：

> **它们都假设「独立于对话与代码的中间产物」是必要的。**

而中间产物这个位置，**两头都夹不过**：

| | 上游 | 下游 |
|---|---|---|
| 需要什么 | **伴随式记忆**（别忘、别自相矛盾、给 AI 当上下文） | **活的对齐**（谁做什么、接口是什么） |
| 已经有什么 | `CLAUDE.md`、memory、ADR | issue tracker、PR、评审、**代码本身** |
| 共同点 | **都是活文档——就地、伴随生长、与代码一起演进** | 同左 |

**中间产物的两头夹击：**

> **比记忆重**（要写、要维护、要读、要人判）
> **比代码旧**（写完那一刻就开始过时，而真相在代码里）

## 四、可复用的判据（本次真正的产出）

这五条不依赖本项目成不成立，是这次最该留下的东西。

### 1. 收敛判据

> **收敛点落在「人能现在给答案」的地方 → 收敛。**
> **收敛点落在「做完才知道」的地方 → 不收敛。**
>
> 业务决策：业务方**现在**就能答 → 收敛。
> 实现决策：答案**在时间上还没到** → 不收敛。

**推论**：任何规格文档，若含实现决策，必然不收敛。**"不含实现"不是妥协，是它成立的唯一条件。**

### 2. 判断成本判据

> **产出的好坏，人能不能低成本判断？**
> 能 → 助手成立（人快速筛，AI 大批量产）。例：代码、文案、翻译。
> 不能 → **助手不成立**（人筛不动 = 等于没筛）。例：需求收集、设计。

**推论**：判断成本高的东西，只能**逐点、人在环**——因为颗粒度一大，判断成本就超线性增长。

### 3. 武器 / 防具 × 可机器验证

|  | **可机器验证** | **不可机器验证** |
|---|---|---|
| **防具**（坏了不自害，只"没防住"） | 完全不用审（lint/格式化，CI 自动闸） | **几乎没人审**（AI 写的单测） |
| **武器**（坏了它自己就是损害源） | 可信任（编译器、形式化证明） | **必须人审**（高并发设计、业务规则） |

**补第三层**：致害时能否**及时发现、归因、回滚**。
坏单测 CI 一红就知道、改掉就行 → 事后修；坏的高并发设计上线才炸、不可回滚 → 事前审。

**推论**：AI 在高代价场景靠**"产出可被既有机器验证的东西"**立足，不是靠"产出可审的东西"。
而既有验证机制（编译器/测试/类型/CI）**与 AI 无关，早就存在**——所以不存在"围绕 AI 的新保证层"。
（新保证层确实有，但针对的是 AI 带来的**新风险**：幻觉、注入、内容安全、溯源。）

### 4. 跨界节点必被实现面拖垮

> **一个横跨"业务决策 / 实现决策"的节点，剥掉实现面之后，剩下的薄到可以并回上游——于是它作为"节点"就消失了。**

三次验证：

| 节点 | 业务面（留） | 实现面（砍） | 归宿 |
|---|---|---|---|
| 页面设计 | 有哪些屏、每屏承载哪些操作 | 怎么排、什么控件、宽窄 | `func.md` 一列 |
| 接口设计 | 有哪些能力（`CAP#`） | 端点、字段、协议 | `resolution.md` |
| 架构设计 | 业务不变量、能力类别 | 机制、拓扑、选型 | `req.md` + 问题库 |

**九个宏观节点 → 约四个**，且**没有一份含实现决策**——"无法一次补齐"从根上消失：不是补齐了，是这类东西不该由我们要。

### 5. 中间产物的生态位

> **中间产物要成立，必须"两头都没有更好的东西"。**
> 而文档两头都比不过：**比记忆重，比代码旧。**

## 五、沿途的实测证据（可复现）

### 5.1 渲染链路不收敛（`demo/` 实测）

用 json-render + 现成 shadcn 目录 + React 跑通了一个 6 屏 / 3 模块 / 带侧边导航的完整可点原型。**能跑，但代价不收敛：**

| 一次性坑（学会就没） | 永久的税（每加一类页面再来一次） |
|---|---|
| Tailwind `@source` 漏配 → 整页无样式 | `Grid(columns=N)` 是等分列 → 列宽失控、控件拉满 |
| `children` 在 schema 里必填（TS 类型标可选） | 单元格对齐（Text/Badge/Button 三种内部对齐不同） |
| `Stack.align` 默认 `start` → 布局塌陷 | 侧边导航「定宽 + 自适应」表达不了（无 flex-grow） |
| 内置 `setState` **静默跳过** `onSuccess` | 响应式重排做不到 |
| `onError` 不带失败原因 | `Table` 单元格放不下控件；无日期控件 |

**规模**：映射层 764 行 + 宿主 186 行 + **171 个 npm 包**；其中 ~560 行是补偿与脚手架。

**根因**：**语义件是复合的，原语是原子的。这个 gap 必须有人填。** 填在映射层不收敛，填在自建组件更贵，**只剩"不填"**。

### 5.2 骨架图收敛，但价值不在

改版为「结构骨架图」后：**451 行纯 Python、零依赖、单文件 HTML**；换 token 不变代码；逐字节确定性。

**但 AI 盲测显示它作为消费品没有优势**（见 5.3）。

### 5.3 AI 消费盲测（四组，隔离 fresh agent）

| 组 | 输入 | 追问 | 自补业务判断 |
|---|---|---|---|
| A | 语义规格 JSON + token | 12 | 12 |
| B | 结构骨架图 HTML | **15** | **15** |
| C | **一句话需求**（baseline） | 7 | **9（全部自标"纯属猜测"）** |
| D | A 组 **抹掉一条反馈措辞** | 11 | 9 |

**三个结论**：

1. **原始条数不可比** —— C 只有 7 条是因为它**连问题在哪都不知道**；A/B/D 能精确指出缺口。**"追问条数"作为指标是失效的。**
2. **三组独立收敛**（A/B/D 互不可见，指到同一批缺口）→ 那些是**产物的客观缺陷**，不是消费者的毛病。实测抓到 7 条，含我自己造的两个 bug（状态筛选 options 与表格值域不一致、样例数据不自洽）。
3. **抹洞测试通过** —— 抹掉措辞后，D 组**回问了，没有自己编**。这是 `CR4`（自包含）在实验上的样子，也是**唯一有效的硬指标**。

**C 组的教训最值钱**：一个称职的 AI 拿一句话需求，产出了完整技术栈 + 8 个屏 + 9 张表 + 状态机，**同时自补了 9 条业务判断，每一条它自己都知道是猜的**。它不会告诉你它替你决定了什么。

### 5.4 外部工具调研

- **墨刀**：**没有"统一规格"进口，只有 HTML 进口**（`import_to_proto` 仅支持 HTML）。且要求删掉 `<script>`、禁 `position:fixed`、图片须公网 URL——**而我们的产物是 JS 渲染的 SPA，删了 script 就是白页**。按判据（素材分离 / token 注入 / 接事件状态 / 装复合语义件）**3 条不过，否掉**。
- **Figma**：写通道卡在 Full seat + MCP Catalog 白名单 + beta。
- **DTCG**：W3C **社区组规范**（CG-FINAL），非 W3C 标准；生态无"页面"输出端。
